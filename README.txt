## Add your profile photo
Replace the `.profile-placeholder` content in `index.html` with:
<img src="profile.jpg" alt="Aditi U Shetty">

Then place `profile.jpg` in this folder.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.
